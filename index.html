Respaldo en la nube (GitHub)

Pega una sola vez tu token de GitHub en este aparato y todo se respalda solo, igual que en la Bitácora.

  1. Abre GitHub → nuevo token.
  2. Nombre: Tendidos. Expiración: la más larga que te deje.
  3. Repository access: Only select repositories → tendidos. Si quieres un solo token para todo, agrega también BITACORA-DE-OBRA y CALAS-TERRACERIAS.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Toca Generate token, cópialo y pégalo aquí.
