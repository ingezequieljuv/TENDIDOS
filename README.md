# Tendidos

Tendido de carpeta y base asfáltica — JUVISA.

App web para el informe de tendido y control de temperatura de mezcla asfáltica: viajes, cadenamientos, temperaturas, registro de obra, fotos, ubicación con mapa satelital, empresas, PDF y Excel.
